## Disposition

No direct string/placeholder mismatch was found in the source-backed Market trade, Casino Void Seer/Higher-Lower, Wheel telescope-claim, or Black Hole notices. The 12 October supplement fills the missing Wheel telescope-claim source-key → target-catalog → event-renderer mapping. Combined with the source-wide notification route audit and the other dated family crosswalks, the notification-to-owner mapping is complete; focused assertions and live locale/layout evidence remain outstanding. Source Market AP sale/liquidation and successful perk/rebirth actions are silent in both implementations. Target-specific Casino purchase feedback remains an added inline route. The first crosswalk recorded the Megastructures New badge as the only target attention route; the implementation follow-up below adds the source-equivalent one-time toast while retaining that badge.

**Implementation follow-up (12 October 2026):** the target now sends `megastructureOptionAvailable` as an informational `tech` notice for 3 seconds when the current system is a recorded factory system, guarded by the persisted `megastructureOptionNotificationShown` flag. The mark-shown command persists the flag before the toast is emitted. Schema v55 migrates older saves with a false initial value because the prior remake state did not record this source notification history. The existing localized New badge and separate Galactic Casino child ownership are unchanged. Static source/code review only; no tests, builds, typechecks, or browser review were run.
