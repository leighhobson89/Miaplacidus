# P-45 Resource and Compound purchase/result copy audit

Audit date: 12 October 2026. This static review compares the relevant Cosmic Forge source messages and current source UI routes with the six-locale MIAPLACIDUS catalogues/renderers. It makes one confirmed Portuguese locale correction. No tests, builds, typechecks, formatters, or browser checks were run.

## Source-to-catalogue-to-renderer evidence

| Message family | Cosmic Forge source | MIAPLACIDUS catalogue and renderer | Finding |
| --- | --- | --- | --- |
| Bulk Hydrogen AutoBuyer shortage | `drawTab1Content.js` renders four Hydrogen AutoBuyer purchase rows with their individual prices; it has no equivalent bulk-buy control or bulk-shortage message. | `src/app/App.tsx:1802-1812` formats `buyMaxInsufficientMaterials` with `{required}`, `{good}`, and `{available}`; `App.tsx:2589` renders the result beside the Hydrogen bulk-buy controls. `formatEconomyMessage()` in `src/i18n/economyMessages.ts:1322-1330` replaces every occurrence of each supplied placeholder. | The six catalogue entries use the same three placeholders. It now reads `São necessários {required} {good}; disponíveis: {available}.`, consistent with the adjacent PT `needGoodAmount` wording. This target-only message has no source string to copy. |
| Resource/Compound sale result | `game.js:5222-5235` (`sellResource`) and `game.js:5378-5391` (`sellCompound`) use `notificationSoldMaterialSymbolBefore` or `notificationSoldMaterialSymbolAfter`, passing amount, material name, cash, and currency according to source currency placement. This message does not require grammatical plural branches. The audit records static catalogue and callsite evidence only; visual rendering and live language switching remain part of the broader P-45 review.
