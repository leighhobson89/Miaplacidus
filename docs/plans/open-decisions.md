# Product decisions for MIAPLACIDUS

These decisions were supplied by the project owner on 2 October 2026 and govern the [master checklist](master-checklist.md). The filename is retained so existing links and work notes continue to resolve. No owner decision remains pending; later clarifications are recorded below.

| Topic | Decision | Consequence for the rebuild |
|---|---|---|
| Identity and scope | **MIAPLACIDUS** is a from-scratch remake of the shipped Cosmic Forge game. Preserve its player-facing mechanics and breadth across the nine source tabs, themes, story/endgame and six languages; the new Miaplaedia reference tab is a presentation addition. | Treat Cosmic Forge code and tests as read-only behavioral evidence. Extract rules and data; write a new application. Record any deliberate rule change. |
| Presentation and navigation | **Owner decision (2026-10-04; updated 2026-10-06):** keep the nine Cosmic Forge source tabs in a stable order and append a new top-level **Miaplaedia** after Settings. **Compounds follows Resources as the second visible tab whenever it is unlocked.** Omit locked main gameplay tabs entirely; the other visible tabs retain their declaration order and are not renumbered internally. Move Get Started, Story, Early/Mid/Late Concepts, End Goal, Philosophies and all remaining Cosmicopedia prose documents out of Settings and into Miaplaedia. Keep the Contact external-link action excluded. |
| Opening briefing | **Owner decision (2026-10-04, reaffirmed 2026-10-05):** permanently remove the one-screen first-run Hydrogen briefing panel and its replay button. | New and resumed runs enter gameplay directly. Do not restore the panel, replay control, or per-slot completion marker. A separate optional progression tutorial now offers resumable early-game, Settings, and Miaplaedia guidance; remaining source-step coverage stays in M-06/P-36. |
| Devices and delivery | Ship a browser game that works on desktop and responsive mobile. **No Electron app or desktop installer.** | Test wide and narrow layouts and current desktop/mobile browsers. A desktop computer uses the browser release. |
| Saving | **No cloud saves, accounts or sync.** Use multiple independent `localStorage` slots and LZString text/clipboard/file export and import. | The name field prefills the last successfully started pioneer. ## P-55 Statistics semantics decisions (12 October 2026)

The owner selected **Use the documented remake behavior** for the three Statistics rows whose semantics had been pending. Keep the current MIAPLACIDUS behavior and do not change these values to mirror Cosmic Forge's source-specific scopes:

- **Time Played / Run Time:** keep active-lifetime time and simulation-run time. Existing saves do not contain a reconstructable wall-clock start anchor, so do not reinterpret or fabricate elapsed history.
- **Star Ship Distance Travelled:** keep completed-route This Run and Lifetime totals; show in-flight progress on the Starship page. Cosmic Forge's two columns instead alias current-trip progress/full distance and reset on rebirth.
- **Enemy Total Defence Overcome:** keep Not Applicable in the remake. Cosmic Forge's label refers to a single-battle start-minus-current enemy-power delta; the remake has no cumulative lifetime meaning for that row.

This resolves the owner-decision subtask under P-55, not its source-value audit. The controlled row comparisons and remaining checklist evidence stay open in the [Statistics parity plan](statistics-presentation-parity.md).

## Working technical decisions

- TypeScript, Vite and React for the browser UI; semantic HTML and responsive CSS. The simulation remains framework-independent and deterministic.
- Vitest for pure rules and Playwright for browser functional areas, following the old project's area-based test and debug approach.
- LZString 1.5.0 for compressed local slots and portable codes. The package is already pinned in the manifest and lockfile.
- Keep future implementation choices in the feature plan that needs them. Amend this record only when the owner changes a product decision; then update the master checklist and affected contracts together.

**Energy after rebirth (12 October 2026):** the owner directed MIAPLACIDUS to follow Cosmic Forge. Dyson Sphere stage 2's 1.25x plant-rate mutation is run-scoped: source rebirth restores initial plant rates and replays Optimized Power Grids, but does not replay the Dyson mutation. A new run therefore retains permanent Dyson technology while its plant-rate boost is inactive. The remake now stores this effect as run state and clears it on rebirth. See the [Dyson rebirth audit](../archive/audits/p55-dyson-production-rebirth-audit-2026-10-12.md).

**Energy rebirth follow-up (12 October 2026):** the same source boundary also resets stage 1's doubled battery capacities and leaves the power grid off unless persistent Dyson stage 5 grants Infinite Power. MIAPLACIDUS now resets the run-scoped stage 1 capacity flag and only restores grid/Infinite Power for stage 5. Stage 4 is permanent technology but does not by itself reactivate Infinite Power in a new run. The v53-to-v54 migration derives the new run flag from stage 1 ownership to preserve the existing save's live behavior. See the [Energy rebirth audit](../archive/audits/p55-energy-rebirth-audit-2026-10-12.md).
