## Source/code time-semantics mismatch (P-55 remains open)

The source and remake use different elapsed-time semantics for both time rows. Cosmic Forge `Time Played` is `Date.now() - getGameStartTime()` and `Run Time` is `Date.now() - getRunStartTime()` ([source getters](../../../cosmicForge/cosmicForge/constantsAndGlobalVars.js#L4946), [timestamp setters](../../../cosmicForge/cosmicForge/constantsAndGlobalVars.js#L5855), [first-start initialization](../../../cosmicForge/cosmicForge/game.js#L2177), [saved timestamp](../../../cosmicForge/cosmicForge/constantsAndGlobalVars.js#L1881), [restored timestamp](../../../cosmicForge/cosmicForge/constantsAndGlobalVars.js#L2220), [rebirth run reset](../../../cosmicForge/cosmicForge/game.js#L15804)). Its offline-adjusted active-time accumulator is computed separately and is not used by either getter ([`calculateElapsedActiveGameTime`](../../../cosmicForge/cosmicForge/game.js#L2233)). The remake's Overview `Time Played` reads `lifetimeActiveMs`, which accumulates elapsed foreground steps ([`SettingsStatisticsPane.tsx`](../../src/app/SettingsStatisticsPane.tsx#L202), [`commands.ts`](../../src/engine/commands.ts#L2285)); its Run `Run Time` reads `run.clock.simulationMs` ([`SettingsStatisticsPane.tsx`](../../src/app/SettingsStatisticsPane.tsx#L147)). This source/code comparison establishes a wall-clock-versus-active/simulation-time mismatch. It does not decide which semantics the remake should adopt. Compare both rows against controlled source states and record the accepted behavior before closing P-55.

## Metrics with ambiguous or inconsistent source semantics

The following decisions are explicitly owner-gated. Preserve the observations below, but do not encode a guessed meaning or scope as parity:

- **Enemy Total Defence Overcome:** the source marks the current-run value Not Applicable, while its all-time getter calculates `max(0, enemyFleetPowerAtBattleStart - currentDestinationFleetPower)`. This is a single battle's start-to-current difference, not a cumulative sum across enemies or runs. Preserve the source observation and seek the intended statistic before adding a counter.
- **Galactic Points Earned versus GP awarded:** Statistics intentionally follows the source proxy `max(0, settledSystemIds.length - 1)` rather than presenting the remake's per-rebirth GP-award ledger (`src/engine/metaProgression.ts`). The row is labeled as the source statistic and is not a claim that it totals GP actually awarded. Verify its source value under a controlled source state before closing P-55.
