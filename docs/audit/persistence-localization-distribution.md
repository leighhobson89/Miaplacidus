# Persistence, localization, and distribution

## Save contracts

The source field and localization-key crosswalks extracted for F-08 are indexed in the [foundation economy](foundation-economy.md), [space/interstellar](foundation-space.md), and [meta/endgame](foundation-meta.md) catalogues. Scope names there are target-model inferences; this document and the [local save contract](../plans/local-save-contract.md) define MIAPLACIDUS behavior.

[saveLoadGame.js](../../../cosmicForge/cosmicForge/saveLoadGame.js) assembles a large game snapshot, compresses it with global `LZString`, and offers text export/import, file download/import, autosave and Supabase cloud storage. [constantsAndGlobalVars.js](../../../cosmicForge/cosmicForge/constantsAndGlobalVars.js) restores cross-run globals and calls into the data stores. [patches.js](../../../cosmicForge/cosmicForge/patches.js) and `migrateResourceData()` provide historical migrations. The current `GAME_VERSION_FOR_SAVES` is `0.992`; the minimum accepted version is `0.93`. The [migration tests](../../../cosmicForge/cosmicForge/tests/e2e/migration/README.md) have a version ladder, while `save-migration` covers malformed/edge cases.

This is a high-consequence boundary. A player can lose many runs of progress if a field is omitted, reset at the wrong scope, double-applied by an offline calculation, or lost while migrating. The remake should define a versioned, validated save schema with explicit `run`, `permanent`, `settings`, and `statistics` ownership. Restoring a save should be atomic: parse, validate, migrate, then commit once. Keep a copy of the original payload on any failed import. Export must work without storage or network. The target [local save contract](../plans/local-save-contract.md) replaces cloud lookup with multiple local slots and loads the confirmed pioneer when Start is pressed.

**Product decision:** original Cosmic Forge save compatibility is excluded. The old `0.93`–`0.992` migration ladder is historical evidence only. MIAPLACIDUS starts its own versioned schema and preserves saves created here across future releases; sanitized fixtures should cover each shipped MIAPLACIDUS version. Do not depend on production Supabase during testing.

The old cloud client is imported from a CDN in `saveLoadGame.js`, and rows are looked up by `pioneer_name`. **This is historical reference behavior, not a remake requirement.** The remake has no cloud-save client or save network request. Its new risks are localStorage quota, corrupt per-slot payloads, stale slot index, duplicate names and two-tab conflicts; the [local save contract](../plans/local-save-contract.md) specifies recovery and tests.

## Localization contract

[localization.js](../../../cosmicForge/cosmicForge/localization.js) supports `en`, `es`, `pt`, `de`, `it`, `fr`. Resolution is requested language, stored preference, browser language, then English; unknown locales fall back. The catalogue parsed on audit date contains 2,621 keys for each language. [validateLocalization.cjs](../../../cosmicForge/cosmicForge/validateLocalization.cjs) gates builds. The old [localization status](../../../cosmicForge/cosmicForge/docs/localization/status.md) says the catalogue was complete at 2,591 keys at its snapshot, which confirms why counts must be taken from current JSON. It also records that translated controls no longer clip under its measured sweep, while wrapping, absolute-position overlaps and modal/tooltip layout still need a human German pass.

The remake should keep stable untranslated IDs for gameplay state, menu panes and save fields; display language must never determine a rule. Define typed translation keys and placeholder contracts, build-time missing/unused/placeholder checks, locale-aware number formatting, pluralization, and safe rich-text rendering. Do not retain `innerHTML` as the default translator output. Exercise every pane, modal, notification, tooltip, achievement and late-game screen in all six languages. Switching language at runtime must redraw text without resetting game state or recomputing rewards.

## Packaging and runtime dependencies

[index.html](../../../cosmicForge/cosmicForge/index.html) loads five external CDN libraries before the app module. A blocked CDN can therefore affect boot or saves. The remake should bundle browser runtime dependencies through its local build and verify offline boot where required. The [build guide](../../../cosmicForge/cosmicForge/docs/making-a-build.md) documents two distinct release pipelines: a Python web/itch packager and a Node/Electron builder. Build flags control demo content, Cosmic Rip and debug/cheat exposure; the guide notes the web packager copies flags as-is. The remake should have explicit build modes with automated checks that debug controls and production endpoints cannot leak into public builds.

Build MIAPLACIDUS for desktop and responsive mobile **browsers only**. The normal build is full; an optional demo has explicit opt-in flags and independently tested restrictions. No release artifact should contain cloud-save code, Electron packaging, analytics collection or original-game save import. Cosmic Rip telemetry is an in-game currency and remains in gameplay.
