# Starship

Click-driven coverage for starship module cost display and payment, required-module readiness, and the optional stellar scanner. `space-starship` is a test-only fixture with all five module technologies, ample stock, and two Space Elevator purchases so the UI and engine use the same discounted quote.

Run with `npm.cmd run test:e2e:focused -- tests/e2e/starship/starship.spec.ts`.

## Current evidence

Both focused Chrome scenarios reported passes. Playwright remained alive after the cases and was stopped manually; it did not write a summary report.
